# Client Roles Setup

## Steps to Assign Roles in Keycloak

1. Go to **Clients** → Select your client (`platform-gateway`).
2. Navigate to **Service accounts roles** → Click the **Assign role** button (blue).
3. **Filter by clients** to refine the list.
4. **Search for role names** such as:
   - `query-users`
   - `query-groups`
   - `view-users`
   - `view-realm`
   - `create-client`
   - `manage-users`
   - `manage-realm`

5. Select the required roles and click **Assign** to grant them.
